## 前端接入方式

数据已按线上结构整理，可直接使用同一套字段读取：

```js
// 全表分片加载后
const arr = window.ARCHIVE_2025 || [];
arr.forEach(x => {
  // x.date / x.name / x.country / x.fields / x.causeOfDeath / x.wikipedia ...
  // 与 window.DEATHS_DATA 完全同名字段，无需映射
});
```

建议仍按年份分片懒加载、内存索引搜索、虚拟滚动渲染列表；默认加载最近 3 年。
