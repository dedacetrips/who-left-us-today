# 人物全表清洗说明

## 源数据

- 文件：`人物全表_116817人.xlsx`（12 MB，1 个工作表，23 列，116,817 行）
- 来源：dead-people.com 抓取 + 维基百科链接（32,741 条）
- 日期跨度：2013-01-01 ~ 2026-11-21

## 清洗脚本

`scripts/clean_full_table.py`（可重复运行，输出覆盖）

## 输出结构

```
archive-data/
├── 2013.js ~ 2026.js    14 个年度分片，window.ARCHIVE_YYYY = [...]
├── meta.json            元数据：国家/领域映射表、统计、各年计数
└── 清洗说明.md
```

## 字段映射

| 原字段 | 输出字段 | 处理 |
|---|---|---|
| id | id | 保留 |
| date | d | 保留，YYYY-MM-DD |
| name / nameOrig | n / no | 中文名优先作为显示名；无中文名则用英文名；两者皆空回退 id |
| country | c | 英文 → 中文，分号分隔多选 |
| age | a | -1 或异常值 → null |
| fields | f | 英文标签 → 11 个中文领域数组 |
| identity | i | 保留 |
| wikipediaUrl | w | 保留 |
| source | s | 保留 |
| causeOfDeath | cd | JSON 字符串 → {label, status}，空则 null |

## 日文名补全（维基百科 / DBpedia）

脚本：`scripts/enrich_jp_names.py`

- 目标：日本籍且显示名无中文的 468 人
- 数据源：英文维基百科条目对应的 DBpedia `rdfs:label`（维基 API 在沙箱内被阻断，改用 DBpedia 直读 JSON）
- 优先级：`zh/zh-cn/zh-hans` 中文标签 > `ja` 日文标签（日文汉字可直接作中文显示名）；纯假名名跳过
- 结果：补全 **210 条**（中文标签 11 条，日文汉字 199 条），如 Eiichi Ohtaki → 大瀧詠一、Jun-Ichi Igusa → 井草準一
- 未补全 258 条：主要是 2026 年新近条目（146 条）无维基链接，DBpedia 未收录
- 补全记录在分片中加 `ns` 字段标记来源（`zh` / `ja`），完整清单见 `name-enrichments.json`
- 日本籍中文名覆盖：237 → **447 / 705（63.4%）**

### 全表其他中文名补全（第二轮）

- 全表无中文名且有维基链接的目标：29,744 条
- **结论：DBpedia 对欧美/印度等人物几乎无中文标签**，抽样 36 条欧美人物命中 0；印度抽样 8 条命中 0（全量跑到 200 条仍 0 命中，已中止）
- 中文圈（中国/中国台湾/韩国/朝鲜）全量跑 114 条，命中 14 条，人工剔除 3 条歧义标签（熊猫「佳佳」「巴斯」、案件名「云南晋宁连环杀人案」），**有效补入 11 条**：
  - 中国：草嬰、张震 (上将)、王世真、释一诚、张阳、朱践耳
  - 韩国：張盛煥、宋榮、金成珉、鄭美景
  - 中国台湾：鄭清文
- 两轮合计补全标记：**221 条**；`ns` 字段保留来源

### 简体中文统一

脚本：`scripts/to_simplified.py`

- 使用 `zhconv`（zh-cn）将所有中文名统一转为**简体中文**
- 转换 **117 条**繁体/日文旧字体，如 大瀧詠一→大泷咏一、紀野一義→纪野一义、井草準一→井草准一、草嬰→草婴、張盛煥→张盛焕
- 额外清理 1 条 DBpedia 歧义标签：`20130221-kaoru-kobayashi`（日本罪犯小林薰）原被误标为案件名「奈良小1女児殺害事件」，已恢复为原名 `Kaoru Kobayashi`
- 转换后中文名总数：**8,104 条**（补全标记 220 条）
- 校验：116,817 条总数不变、14 个分片语法通过、台港澳表述违规 0 条

## 后续使用

年度分片按 `window.ARCHIVE_YYYY` 挂载，页面按年份动态插入 `<script>` 懒加载。
