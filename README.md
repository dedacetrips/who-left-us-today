# 今天谁离开了我们

每天离世的世界名人讣告档案。纯静态站点，无后端、无数据库、无构建步骤。

## 目录结构

```
今天谁离开了我们/
├── index.html              页面与交互逻辑（一般不用改）
├── data/
│   ├── deaths.js           人物数据（改这个）
│   └── obits.js            讣告原文库，按 id 索引，打开详情时懒加载（177 KB）
├── assets/
│   └── portraits/          头像 WebP，192×192 透明底
├── obits/                  讣告长文 Markdown 源（归档用，页面不读）
├── logo.svg                彼岸花标志
└── README.md
```

## 加一个人

**第一步，放头像。**
准备一张白色线稿 PNG（透明底），命名规则：

```
assets/portraits/YYYYMMDD-英文名.webp
```

例如 `20261120-john-doe.webp`。规格：192×192、RGBA、WebP 质量 84，单张约 5–6 KB。没有照片就不放，页面会自动回退成姓名首字方块。

**第二步，加一条数据。**
打开 `data/deaths.js`，在数组开头插入：

```js
{
  "id": "20261120-john-doe",
  "date": "2026-11-20",
  "name": "约翰·多伊",
  "nameOrig": "John Doe",
  "country": "美国",
  "age": 82,
  "fields": ["文学"],
  "identity": "小说家 · 某某奖得主",
  "summary": "一句话概括他为什么值得被记住。",
  "bio": "两三段生平，讲清楚他做过什么、留下了什么。",
  "facts": ["事实要点一", "事实要点二"],
  "obit": null,
  "portrait": "assets/portraits/20261120-john-doe.webp",
  "source": "来源：维基百科 2026 年 11 月逝世人物列表"
}
```

**第三步，刷新页面。** 完毕。

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识，建议 `日期-英文名`，用于锚点与排序稳定 |
| `date` | 是 | 逝世日期，`YYYY-MM-DD`。页面按此日期分组、排序 |
| `name` | 是 | 中文名 |
| `nameOrig` | 否 | 原文姓名，显示在详情页姓名下方 |
| `country` | 是 | 国别 |
| `age` | 是 | 享年（数字） |
| `fields` | 是 | 领域标签，决定筛选按钮。固定为以下 11 个之一：科技、文艺、影视、军政、社科、体育、医药、商业、传媒、宗教、其他 |
| `identity` | 是 | 身份，一句话 |
| `summary` | 是 | 卡片上的一句话，用户最先读到的就是这句 |
| `bio` | 是 | 生平正文 |
| `facts` | 否 | 事实要点数组，详情页列表展示 |
| `obit` | 否 | 讣告全文。填字符串则详情页多出一段「讣告原文」；`null` 则整段隐藏 |
| `portrait` | 否 | 头像路径。`null` 时回退为姓名首字方块 |
| `source` | 否 | 来源标注 |

## 关于「今天」

`index.html` 第 461 行附近有：

```js
const TODAY = new Date(2026, 10, 16);   /* demo 数据的「今天」 */
```

- 正式上线后，改成 `const TODAY = new Date();`，页面就以真实当天为基准
- 当前固定为 2026-11-16，是因为 demo 数据截止 11 月 14 日，往后留了空白日段用于展示「今天还没有人离开」的状态

## 讣告原文

讣告存在 `data/obits.js` 里，按人物 `id` 索引，共 116 条、约 5.9 万字：

```js
window.OBITS = {
  "2026-09-04-102": {
    "level": "官方发布·媒体节选",
    "text": "中国共产党优秀党员……",
    "source": "中国海洋大学官方讣告"
  }
}
```

**页面不直接显示讣告**。详情页里是一个「阅读讣告原文」按钮，点击才展开。`obits.js` 也是懒加载——第一次点按钮时才请求，不占首屏。

三个级别：

| level | 含义 | 条数 |
|---|---|---:|
| 官方完整讣告 | 含落款单位、治丧机构、告别仪式安排 | 38 |
| 官方发布·媒体节选 | 官方渠道发布，但无完整落款格式 | 71 |
| 无公开讣告 | 确证查不到官方文本，只留说明 | 7 |

**给某个人加讣告**：在 `obits.js` 里按 id 加一条，再到 `deaths.js` 里把该人的 `obit` 字段设为 `true`，详情页就会出现按钮。`obit` 为 `null` 的人不显示按钮。

## 本地预览

双击 `index.html` 即可，无需服务器。数据通过 `<script src>` 加载，不受浏览器 file:// 的跨域限制。

## 部署

**Vercel**
```bash
npx vercel --prod
```
或直接在 Vercel 网页端导入本目录。域名在 Settings → Domains 绑定。

**腾讯云 COS / 阿里云 OSS**
整个目录上传到静态网站根目录，开启静态网站托管即可。纯静态，无路由规则。
